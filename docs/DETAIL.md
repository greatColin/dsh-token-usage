# Token 用量

两个入口，同一份数据：

- **对话 / 轨迹旁的「用量」页签**：整幅仪表盘布局（指标条 + 层叠面积趋势图，悬浮显示该时段明细），默认只看当前会话、范围「全部」，清空选择即可看全部会话。
- **设置 → Token 用量**：紧凑表单布局，默认全部会话、近 7 天，适合做全局回顾。

按小时或按天统计模型调用消耗，可以只挑几个会话（按工作区筛选、搜索标题、连同子代理一起统计）。

## 功能

- 七个指标：总 Token、未缓存输入、输出、缓存读、缓存写、缓存命中率、调用次数。
- 趋势图：未缓存输入 / 输出 / 缓存读 / 缓存写四层堆叠面积图，横轴随范围与本页「自动 / 小时 / 天」选择切换。
- 时间范围：今天、近 7 天、近 30 天、自定义起止日期（起始晚于结束会提示，不发起查询）。
- 会话范围：不选 = 全部；「最近会话」一键选中最近活动的会话；也可打开选择器按工作区分组勾选、搜索、整组全选/取消。
- 手动刷新与「重建数据」（重新扫描全部会话日志，几秒）。

## 数据口径

- 只统计 `assistant/message` / `assistant/attempt` 里的 usage 结算；同一步骤重复结算按「最后一次计费、先前那条不计费」处理，重试则各自计费。
- fork 会话只统计继承切点之后的消耗，和父会话相加不会重复。
- 缓存命中率 = 缓存读 ÷（未缓存输入 + 缓存写 + 缓存读）。
- 按天分桶在浏览器本地时区完成，因此跨时区看到的「日」以查看者为准。
- 数据来自本机 `$DSH_HOME/sessions` 的会话日志；页面打开或刷新时按文件修改时间增量重读，同一会话的旧行会被整体替换，重复扫描不会重复计数。

## 已知限制

- 只有 Token，没有费用：本机没有价目表，费用属于估算，不在本页展示。
- 不是官方账单，数字只代表本机日志记录的用量。
- 会话被删除后，它的历史行仍保留在本地表中（除非手动重建）。
- 选择器一次最多渲染 200 个会话，更多请用搜索缩小范围。
